# Content Factory Reference

Use this file for keyword strategy, cluster maps, content briefs, outlines, refresh plans, consolidation, editorial systems, and scalable production.

## 1) Content strategy sequence

1. Define the business goal and conversion event.
2. Identify the market category, adjacent problems, and customer language.
3. Segment opportunities into:
   - brand
   - nonbrand commercial
   - comparison / alternative
   - problem-aware informational
   - product-led support/docs/help
   - local intent
   - use-case / persona
4. Cluster by **intent + page type + conversion path**, not just semantic similarity.
5. Score clusters by:
   - business value
   - addressable demand
   - competitiveness / authority gap
   - content effort
   - support needed from links / brand / product
6. Assign the best page format:
   - category
   - service page
   - landing page
   - comparison page
   - solution page
   - guide
   - template
   - tool / calculator
   - docs/help article
   - location page

## 2) Build around page archetypes, not keyword lists

For each cluster decide:
- the canonical target page
- supporting pages
- internal-link parent
- internal-link children
- CTA and conversion path
- proof needed
- update cadence
- distribution angle

## 3) Content brief requirements

A strong brief should specify:
- page goal
- audience and buying stage
- primary intent
- recommended page type
- title direction
- H1 options
- must-cover sections
- subtopics and questions
- proof / evidence needed
- product/service tie-in
- internal links
- schema opportunities
- CTA(s)
- information gain requirement
- risks to avoid

## 4) Information gain rules

Do not create pages that merely rephrase the SERP. Push for one or more of:
- proprietary data
- original examples
- clearer frameworks
- stronger implementation detail
- better UX
- specialized industry/geographic angle
- comparison depth
- templates, worksheets, calculators, tools
- stronger proof and product relevance

## 5) Refresh vs consolidate vs create net-new

### Refresh when:
- the page already earns impressions
- intent is still right
- CTR, coverage, freshness, or proof is weak

### Consolidate when:
- multiple pages compete for the same intent
- templates created near-duplicates
- links and equity are scattered

### Create net-new when:
- there is no real target page
- the SERP rewards a distinct page type
- current pages cannot be adapted cleanly

## 6) Programmatic content rules

Programmatic or scaled content is acceptable only when:
- each page serves a real intent
- templated data is truly useful
- pages differ materially
- there is local / product / feature / data uniqueness
- pages are internally discoverable
- index bloat is actively managed

Avoid:
- city-swap boilerplate
- low-value location variants
- thin glossary spam
- mass-generated pages with no differentiator

## 7) Editorial system design

For content ops, define:
- ideation source
- prioritization logic
- brief owner
- SME/proof requirement
- drafting standard
- editing standard
- publishing QA
- refresh cadence
- post-publish distribution
- performance review cadence

## 8) Distribution and support

Support content with:
- internal-link campaigns
- newsletter placement
- social distribution
- founder/SME amplification
- partner sharing
- PR hooks when the asset deserves it
- retargeting to strengthen demand and conversion
