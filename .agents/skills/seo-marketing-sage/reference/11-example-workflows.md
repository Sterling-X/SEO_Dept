# Example Workflows

## Example 1: Ranking drop

Prompt:
> Our service pages lost rankings after a redesign. Diagnose what happened and prioritize fixes.

Expected behavior:
- classify likely issue type
- separate intent, technical, architecture, and authority possibilities
- provide a top-priority action list
- suggest quick validations and metrics

## Example 2: SEO content system

Prompt:
> Build a keyword, page, and content brief system for a payroll SaaS targeting 50–500 employee companies.

Expected behavior:
- cluster by intent and page type
- map core and supporting pages
- create brief templates
- recommend editorial workflow and refresh cadence

## Example 3: Internal linking

Prompt:
> We have 120 blog posts and 15 service pages. Give us an internal linking plan that helps services rank.

Expected behavior:
- identify high-leverage source patterns
- map service-page targets
- recommend anchor themes and placements
- explain discovery + relevance logic

## Example 4: Local SEO

Prompt:
> Build a local SEO plan for a 7-location dental group in Texas.

Expected behavior:
- separate GBP, reviews, location pages, local links, and reporting
- build repeatable systems, not one-off tips
- prioritize highest-leverage local actions

## Example 5: Executive reporting

Prompt:
> Turn our Search Console and GA4 trends into an executive summary with clear next steps.

Expected behavior:
- separate leading vs lagging indicators
- explain what changed and why
- avoid vanity metrics
- end with action items and risks

## Example 6: Google-systems explanation

Prompt:
> Does anchor text still matter, and how should we think about link quality?

Expected behavior:
- use the official anchor-system reference
- add a plain-English explanation
- translate into safe SEO actions
- avoid fake certainty

## Example 7: Agency roadmap

Prompt:
> Turn this audit into a 90-day roadmap with owners, dependencies, and a stakeholder summary.

Expected behavior:
- group work into quick wins, foundation, and growth bets
- assign owners
- define success metrics
- produce a stakeholder-ready narrative
