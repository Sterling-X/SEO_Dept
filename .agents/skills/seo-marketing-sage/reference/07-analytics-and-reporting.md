# Analytics and Reporting Reference

Use this file for KPI trees, dashboards, executive reporting, segmentation, forecasting, and SEO experiments.

## 1) KPI hierarchy

Separate leading and lagging indicators.

### Leading indicators
- impressions
- ranking distribution
- CTR
- indexed URLs
- pages receiving impressions
- nonbrand clicks
- local pack visibility
- internal-link coverage
- referring domains / mentions

### Lagging indicators
- qualified organic sessions
- leads / trials / demos / sales
- assisted conversions
- pipeline / revenue
- location-level outcomes
- CAC/LTV-aligned performance where available

## 2) Essential segments

Default segments:
- brand vs nonbrand
- page type
- directory / template
- geography
- device
- location pages vs non-location pages
- new vs refreshed content
- pre/post launch or pre/post experiment

## 3) Reporting narrative

Tell the story in this sequence:
1. what changed
2. where it changed
3. why it likely changed
4. what we did or will do
5. how we will know if it worked

Avoid vanity reporting detached from business outcomes.

## 4) Measurement for major workstreams

### For content
- impressions and clicks by cluster
- CTR by title/snippet changes
- conversions by page type
- assisted conversions
- scroll/engagement where useful

### For technical work
- indexed pages
- crawl behavior
- error counts
- template recovery
- traffic to affected sections
- conversions on recovered pages

### For authority work
- referring domains
- mentions
- referral sessions
- assisted conversions
- branded search trend
- ranking improvement on supported pages

### For local work
- GBP actions
- local pack visibility
- calls / directions / bookings
- reviews
- location-page conversions

## 5) Forecasting rules

Be conservative.
Use ranges, not fake precision.
Show assumptions:
- baseline traffic
- likely CTR change
- ranking movement assumption
- conversion rate
- seasonality
- implementation timeline

## 6) Experiment design

Every SEO experiment should specify:
- hypothesis
- change
- scope
- time window
- expected leading indicator
- success threshold
- confounders
- rollback rule if relevant
