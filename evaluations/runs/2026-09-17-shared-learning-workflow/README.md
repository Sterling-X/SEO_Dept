# Shared Learning Workflow Evaluation

Date: 2026-09-17  
Source task: Extend the existing SEO_Dept agents, MemPalace integration, lesson router, and recursive-self-improvement system into one automatic shared learning workflow.  
Verification state: Scenario-checked behavior and bounded technical lifecycle checks.

## Frozen evaluation design

**Capability under test:** A relevant lesson discovered or retrieved by one participating agent reaches a later relevant agent through shared read-only recall or a source-linked coordinator handoff, changes the later agent's bounded decision appropriately, and does not leak into unrelated work or promote an unsupported hypothesis.

**Representative case:** The documented `FL-M008` High-Conflict Divorce correction is suitable because its earlier exclusive-edge behavior was demonstrably wrong, its link authorities and counterexamples are source-controlled, and the local workflow has focused deterministic tests. This evaluates lesson routing and decision use, not content production.

**Inclusion boundaries:** One original `FL-M008` case, one different applicable explicit-edge case, one unrelated Service Credit Union control, one unsupported SEO claim, direct child-agent palace access, and source-linked fallback when recall has no applicable memory. Client content, legal claims, live publication, rankings, traffic, leads, and broader Situational-page readiness are excluded.

**Completion criteria:**

1. A child agent demonstrates actual read access to wing `seo_dept`; a miss is reported as a miss.
2. The coordinator supplies the applicable source-controlled lesson when recall does not contain it.
3. A later relevant agent applies the original and different-case authorities correctly.
4. The unrelated control remains unaffected and the unsupported claim is not promoted.
5. Existing mechanics tests still pass.
6. Automatic save, fresh-session recall, duplicate prevention, and destructive-operation approval boundaries are recorded as passing only after separate end-to-end evidence exists.

The criteria were fixed before evaluating the later agent's response. More memories, output, agents, or review rounds do not count as improvement.
